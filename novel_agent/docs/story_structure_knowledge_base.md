# 小说续写与创作剧情结构知识库

## 文档目标

- 用途：为小说续写系统提供可检索的剧情动机、篇章主线、梗概结构框架。
- 使用范围：单个独立篇章、单场景推进、章节梗概设计、桥段检索、续写前规划。
- 证据说明：
  - 原始事实：尽量基于原书、原作者公开介绍或图书目录信息。
  - 二级资料：使用写作教学网站、课程页面、评论性综述进行归纳。
  - 推断结论：本文中“适用场景”“续写用途”“组合建议”属于整理性推断，便于工程落地，不视为原作者原话。

## 检索入口建议

- 如果目标是为单章寻找“故事为什么发生”：优先检索“波尔蒂三十六种戏剧情境”“托比亚斯20个主情节”。
- 如果目标是为整章或梗概安排“先后节拍”：优先检索“三幕式结构”“救猫咪”“弗莱塔格金字塔”“故事圆环”。
- 如果目标是为长篇到章节的逐层展开：优先检索“雪花法”。
- 如果目标是弱冲突、重转折、重对照：优先检索“四段式起承转结”。

## 一、用于单个独立篇章主线动机

### 1. 波尔蒂《三十六种戏剧情境》

#### 定义

- 乔治·波尔蒂认为，故事中的基础戏剧情境可以归纳为 36 种。
- 它更像“核心冲突原型库”，适合在章节级别快速确定一条主线动机。
- 最适合解决的问题：这一章到底围绕什么冲突展开。

#### 对续写系统的工程价值

- 适合作为 `chapter_main_drive` 或 `scene_conflict_type` 的候选枚举。
- 适合与角色关系状态、世界规则、事件类型组合，生成单章主线。
- 适合用于检索相似桥段，而不是直接替代完整剧情结构。

#### 36 种戏剧情境清单

| 编号 | 情境名称 | 最简说明 | 常见章节目标 |
| --- | --- | --- | --- |
| 1 | 哀求 | 被迫害者向权威求助 | 求援、求情、求保护 |
| 2 | 营救 | 受害者遭遇危险，被他人救出 | 救人、脱困、建立信任 |
| 3 | 为罪复仇 | 犯罪未受惩罚，复仇者追讨 | 追责、复仇、正义补偿 |
| 4 | 为亲族复仇 | 加害者与复仇者共享亲缘纽带 | 家族撕裂、伦理冲突 |
| 5 | 追捕 | 逃亡者被追缉或追杀 | 逃脱、转移、躲藏 |
| 6 | 灾祸 | 权势、秩序或个体突然崩塌 | 局势逆转、失守、败亡 |
| 7 | 沦为残酷或不幸的猎物 | 无辜者受命运或强者伤害 | 吃亏、受创、压迫展示 |
| 8 | 反抗 | 弱者对强权起而反抗 | 起义、违命、反制 |
| 9 | 冒险行动 | 主角为目标采取高风险行动 | 潜入、突袭、夺取 |
| 10 | 绑架 | 一方掳走关键人物 | 抢人、救人、交换筹码 |
| 11 | 解谜 | 主角需要破解谜团 | 调查、推理、揭露真相 |
| 12 | 获取 | 围绕某个对象、资格或利益展开争夺 | 争取、谈判、竞夺 |
| 13 | 亲族仇恨 | 亲人之间的怨恨和敌对 | 冷战、决裂、对抗 |
| 14 | 亲族竞争 | 亲近者围绕同一对象竞争 | 争宠、争位、争爱 |
| 15 | 致命通奸 | 不正关系引发谋杀或毁灭 | 欺瞒、背叛、灭口 |
| 16 | 疯狂 | 失常、执念或精神崩坏造成破坏 | 失控、误伤、灾变 |
| 17 | 致命轻率 | 因疏忽无知造成严重后果 | 误判、酿祸、补救 |
| 18 | 不自觉的爱情之罪 | 爱情触犯禁忌而不自知 | 身份揭露、伦理震荡 |
| 19 | 误杀亲人 | 不识真相而杀害亲族 | 悲剧揭晓、不可逆后果 |
| 20 | 为理想自我牺牲 | 为信念放弃重要的人或物 | 抉择、立场确认 |
| 21 | 为亲族自我牺牲 | 为亲人承担代价 | 保护、代偿、牺牲 |
| 22 | 为激情牺牲一切 | 为欲望、爱情或执念付出全部 | 失控投入、走向极端 |
| 23 | 为亲者牺牲必要之物 | 在亲情与现实义务间两难 | 两难选择、沉重代价 |
| 24 | 强者之间的竞争 | 地位接近者对抗同一目标 | 争锋、比试、博弈 |
| 25 | 通奸 | 关系越界导致冲突与后果 | 情感裂缝、秘密关系 |
| 26 | 爱情犯罪 | 爱引发背叛、伤害或罪行 | 扭曲占有、越界行动 |
| 27 | 发现所爱之人的耻辱 | 对理想化对象产生幻灭 | 信念崩塌、关系重估 |
| 28 | 爱情障碍 | 相爱但遭阻碍 | 阻隔、试探、错失 |
| 29 | 爱上敌人 | 爱与敌对身份冲突 | 暧昧、背德、摇摆 |
| 30 | 野心 | 为权位或成就不择手段 | 上位、争权、清除阻碍 |
| 31 | 与神或权威冲突 | 挑战更高秩序或禁忌 | 越界、犯禁、承压 |
| 32 | 错误嫉妒 | 因误判而嫉妒怀疑 | 误会、试探、关系受损 |
| 33 | 误判 | 决策基于错误认知 | 冤屈、误伤、剧情反噬 |
| 34 | 悔恨 | 过错已成，人物回头自责 | 补偿、忏悔、迟来的行动 |
| 35 | 失而复得 | 寻回失去之人或物 | 寻找、确认、归位 |
| 36 | 失去所爱 | 爱人或珍视对象被夺走 | 悼亡、空缺、行动触发 |

#### 使用建议

- 单章先选 1 个主情境，不建议一章塞入 3 个以上主情境。
- 若是关系推进章，优先用 `28 爱情障碍`、`29 爱上敌人`、`32 错误嫉妒`、`34 悔恨`。
- 若是动作推进章，优先用 `5 追捕`、`9 冒险行动`、`10 绑架`、`11 解谜`。
- 若是黑化或价值抉择章，优先用 `20`、`22`、`30`、`31`。

### 2. 罗纳德·托比亚斯《20个主情节》

#### 定义

- 托比亚斯将常见故事深层结构归纳为 20 个主情节。
- 相比波尔蒂，托比亚斯更像“完整故事驱动模型”，更强调角色推进方式和情节运行逻辑。
- 最适合解决的问题：这一章或这一段故事的推进方式是什么。

#### 对续写系统的工程价值

- 适合作为 `plot_driver` 或 `chapter_plot_mode`。
- 比波尔蒂更适合生成“梗概级主线”，因为它同时包含事件走向与人物变化方式。

#### 20 个主情节清单

| 编号 | 主情节 | 最简说明 | 适合的章节推进 |
| --- | --- | --- | --- |
| 1 | 探索 | 主角寻找某物、某人、某地或某答案 | 任务线、旅程线、目标线 |
| 2 | 冒险 | 主角进入未知环境，持续遭遇事件 | 开地图、拓世界、连续遭遇 |
| 3 | 追逐 | 一方追，一方逃 | 缉拿、逃亡、时限压力 |
| 4 | 营救 | 关键人物被困，主角设法救回 | 救援、渗透、搭救 |
| 5 | 逃脱 | 主角被困于强控制环境，寻求逃离 | 监禁、围困、封锁 |
| 6 | 复仇 | 受害者向加害者讨还 | 清算、复仇、讨公道 |
| 7 | 谜题 | 核心驱动是未知事物的破解 | 推理、调查、情报揭露 |
| 8 | 竞争 | 双方围绕单一目标较量 | 比赛、夺位、争取名额 |
| 9 | 弱者逆袭 | 弱势一方挑战强势秩序 | 成长、反压迫、翻盘 |
| 10 | 诱惑 | 人物面对欲望、捷径或道德试炼 | 试探、堕落、意志考验 |
| 11 | 变形 | 人物因外在或内在原因发生异变 | 异化、怪物化、身份变化 |
| 12 | 转变 | 人物完成较明确的内在改变 | 认知改变、价值转向 |
| 13 | 成熟 | 人物从幼稚走向承担 | 少年成长、责任觉醒 |
| 14 | 爱情 | 人物建立并发展情感连接 | 相识、试探、确认关系 |
| 15 | 禁忌之爱 | 爱情遭受身份、伦理或秩序阻碍 | 敌对恋、阶层恋、禁令恋 |
| 16 | 牺牲 | 为更高目标放弃自身利益 | 舍弃、代价、担当 |
| 17 | 发现 | 主角发现真相，也重新认识自我 | 身世揭露、世界揭露、顿悟 |
| 18 | 过度沉溺 | 人物因欲望无节制而自毁 | 堕落、沉迷、失控 |
| 19 | 上升 | 人物地位、能力、权力不断上升 | 晋升、崛起、掌权 |
| 20 | 下降 | 人物地位、道德、精神不断坠落 | 失势、腐化、崩坏 |

#### 使用建议

- 如果需要“单章强目标”，优先用 `1 探索`、`3 追逐`、`4 营救`、`7 谜题`。
- 如果需要“人物关系推进”，优先用 `14 爱情`、`15 禁忌之爱`、`16 牺牲`、`17 发现`。
- 如果需要“人物弧光推进”，优先用 `10 诱惑`、`12 转变`、`13 成熟`、`18 过度沉溺`、`20 下降`。

### 3. 波尔蒂与托比亚斯的使用分工

| 维度 | 波尔蒂 36 | 托比亚斯 20 |
| --- | --- | --- |
| 核心作用 | 提供基础冲突原型 | 提供推进型主线 |
| 粒度 | 更适合单章主冲突 | 更适合章节到篇章梗概 |
| 长处 | 快速定冲突 | 快速定推进方式 |
| 常见误用 | 罗列情境但没有节拍 | 只有套路名没有具体冲突 |
| 建议组合 | 先定情境，再选主情节 | 先定主情节，再补具体戏剧情境 |

#### 推荐组合模板

- `波尔蒂情境 + 托比亚斯主情节 + 角色关系状态 + 世界规则限制`
- 示例：
  - `11 解谜 + 17 发现`：调查章、真相揭露章。
  - `28 爱情障碍 + 14 爱情`：暧昧推进章。
  - `5 追捕 + 3 追逐`：逃亡章、缉捕章。
  - `20 为理想自我牺牲 + 16 牺牲`：立场抉择章。

## 二、用于故事梗概与章节节拍

### 1. 三幕式结构

#### 定义

- 最常见的宏观故事框架：开端、对抗、解决。
- 常见表达：`Setup / Confrontation / Resolution`。
- 适合先快速搭出梗概骨架，再往里填人物弧和桥段。

#### 典型结构

| 幕 | 作用 | 关键问题 |
| --- | --- | --- |
| 第一幕 | 建立人物、世界、目标、诱发事件 | 故事为什么开始 |
| 第二幕 | 冲突升级、障碍叠加、代价上升 | 主角为什么不能轻易成功 |
| 第三幕 | 决战、抉择、结果、余波 | 主角最终付出什么并改变了什么 |

#### 常见关键节点

- 开场状态：主角原本的稳定状态。
- 诱发事件：打破稳定状态，迫使故事开始。
- 第一转折：主角真正进入主要冲突。
- 中点：认知、局势或策略发生明显变化。
- 黑暗时刻：主角看似接近失败或失去关键事物。
- 高潮：核心冲突正面解决。
- 收束：展示改变后的新状态。

#### 对续写系统的价值

- 适合生成章节梗概模板。
- 适合在长篇中判断某章所处位置。
- 适合把“当前章”定义为：铺垫章、升级章、转折章、高潮章、收束章。

### 2. “救猫咪”节拍表

#### 定义

- 布莱克·斯奈德提出的 15 节拍结构。
- 相比三幕式，它更像“节拍级执行模板”，能回答“这一段该发生什么”。
- 非常适合把一个故事梗概细分成更具体的剧情节点。

#### 15 个节拍

| 节拍 | 作用 | 常见问题 |
| --- | --- | --- |
| Opening Image | 开场画面，展示旧状态 | 主角原本处于什么处境 |
| Theme Stated | 点出主题命题 | 这故事最终在讨论什么 |
| Setup | 建立人物、关系、缺口 | 主角缺什么，世界缺什么 |
| Catalyst | 催化事件 | 什么打破了平衡 |
| Debate | 犹豫与争论 | 主角要不要进入主线 |
| Break into Two | 进入第二幕 | 主角正式踏入新局 |
| B Story | 副线进入 | 哪条关系线或主题线开始发挥作用 |
| Fun and Games | 核心设定兑现 | 读者最期待看到的内容是什么 |
| Midpoint | 中点转折 | 局势是假胜还是假败 |
| Bad Guys Close In | 压力收紧 | 敌人、问题或内在缺陷如何逼近 |
| All Is Lost | 一切尽失 | 主角失去关键支点 |
| Dark Night of the Soul | 黑夜时刻 | 主角如何面对内在崩溃 |
| Break into Three | 进入第三幕 | 主角如何找到新的解法 |
| Finale | 终局执行 | 新旧资源怎样合并完成最终行动 |
| Final Image | 结尾画面 | 主角与世界发生了什么变化 |

#### 用于小说梗概时的简化方式

- 短篇或单章可以压缩为 `开场 -> 催化 -> 进入主冲突 -> 中点变化 -> 一切尽失 -> 决断 -> 结尾对照`。
- 关系章可把 `B Story` 作为情感线主入口。
- 冒险章可把 `Fun and Games` 视为“设定兑现段”。

#### 注意事项

- “救猫咪”很适合商业叙事，但容易模板感过强。
- 在续写中不应死套页码比例，应保留原作语气、节奏和留白。

### 3. 弗莱塔格金字塔

#### 定义

- 经典五段式戏剧结构：开端、上升、高潮、下降、结局。
- 适合悲剧、悬疑、强因果链故事。

#### 五段

| 段落 | 作用 |
| --- | --- |
| Exposition | 建立背景与前提 |
| Rising Action | 冲突不断上升 |
| Climax | 情势达到峰值并发生关键转折 |
| Falling Action | 高潮后果展开 |
| Catastrophe / Resolution | 悲剧性崩塌或结局性收束 |

#### 工程用途

- 适合标注“这一章是上升还是后果章”。
- 适合把悲剧型篇章拆成因果链。

### 4. 英雄之旅

#### 定义

- 约瑟夫·坎贝尔的“单一神话”模型，后续被大量编剧教材简化使用。
- 强调主角从熟悉世界进入陌生世界，再带着变化返回。

#### 常见 12 阶段简表

| 阶段 | 作用 |
| --- | --- |
| 平凡世界 | 展示旧日常 |
| 冒险召唤 | 事件召唤主角行动 |
| 拒绝召唤 | 主角犹疑 |
| 遇见导师 | 获得引导或工具 |
| 跨越门槛 | 正式进入新世界 |
| 试炼、盟友、敌人 | 主线冲突展开 |
| 接近洞穴深处 | 接近核心危机 |
| 苦难考验 | 经历重大试炼 |
| 奖赏 | 获得成果或关键认知 |
| 回归之路 | 回返或准备决战 |
| 复活 | 最终蜕变与终极试炼 |
| 带着灵药归来 | 带着变化回归秩序 |

#### 工程用途

- 适合成长线、史诗线、冒险线。
- 不太适合完全日常流、群像切片流、弱目标叙事。

### 5. 丹·哈蒙故事圆环

#### 定义

- 可视为英雄之旅的压缩版，共 8 步。
- 适合单集、单章、单段剧情循环，便于快速规划。

#### 8 步

| 步骤 | 含义 |
| --- | --- |
| You | 主角处于熟悉区域 |
| Need | 主角产生需求 |
| Go | 进入陌生处境 |
| Search | 适应、摸索、碰壁 |
| Find | 得到想要的东西 |
| Take | 为此付出代价 |
| Return | 带着结果返回 |
| Change | 主角发生变化 |

#### 工程用途

- 很适合章节级规划。
- 可直接作为 `scene mini arc` 的模板。
- 适合“本章有进入、有代价、有变化”的强闭环写法。

### 6. 雪花法

#### 定义

- 兰迪·英格曼森提出的逐层展开式规划方法。
- 不是剧情模板，而是“从一句话扩展到完整故事”的设计流程。

#### 核心思路

- 从一句话梗概开始。
- 扩展成一段摘要。
- 扩展人物卡。
- 再扩展为更长摘要、场景列表、完整草案。

#### 工程用途

- 非常适合构建自动化梗概生成流水线。
- 可用于：
  - `一句话主线`
  - `一段式章节摘要`
  - `角色目标/动机/冲突`
  - `场景列表`
  - `章节草稿`

#### 与续写任务的关系

- 如果用户只给了一个续写目标，雪花法适合作为从“目标”到“ScenePlan”的中间层。
- 如果已经有明确锚点文本，雪花法应作为整理工具，而非强行改写原作节奏。

### 7. 起承转结

#### 定义

- 东亚常见的四段式结构：起、承、转、结。
- 核心不一定依赖强冲突，更强调信息展开、视角转换和意义上的转折。

#### 四段

| 段落 | 作用 |
| --- | --- |
| 起 | 提出场景、人物、状态 |
| 承 | 延展、补充、深化 |
| 转 | 出现意外变化、对照或重新理解 |
| 结 | 收束并形成余味 |

#### 工程用途

- 很适合短篇、散文式小说、日常流、轻推理、意境型章节。
- 适合原作本就克制、留白多、冲突弱的作品续写。

## 三、面向续写系统的组合建议

### 1. 单章主线生成推荐顺序

1. 先选一个 `主情节`：如探索、营救、竞争、发现。
2. 再选一个 `戏剧情境`：如解谜、追捕、爱情障碍、悔恨。
3. 再给出 `结构模板`：三幕式、故事圆环、救猫咪压缩版。
4. 最后绑定 `角色目标 / 情绪目标 / 冲突目标 / 结尾钩子`。

### 2. 适配关系推进章

- 推荐主情节：`爱情`、`禁忌之爱`、`发现`、`牺牲`。
- 推荐戏剧情境：`爱情障碍`、`爱上敌人`、`错误嫉妒`、`悔恨`。
- 推荐结构：`故事圆环` 或 `救猫咪压缩版`。

### 3. 适配动作事件章

- 推荐主情节：`追逐`、`营救`、`逃脱`、`探索`。
- 推荐戏剧情境：`追捕`、`营救`、`绑架`、`冒险行动`。
- 推荐结构：`三幕式` 或 `弗莱塔格金字塔`。

### 4. 适配成长转变章

- 推荐主情节：`成熟`、`转变`、`发现`、`牺牲`。
- 推荐戏剧情境：`为理想自我牺牲`、`致命轻率`、`悔恨`、`与权威冲突`。
- 推荐结构：`英雄之旅` 或 `故事圆环`。

### 5. 适配弱冲突与文艺向章节

- 推荐主情节：`发现`、`爱情`、`转变`。
- 推荐戏剧情境：`失而复得`、`发现所爱之人的耻辱`、`爱情障碍`。
- 推荐结构：`起承转结`。
